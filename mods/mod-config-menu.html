Description

This mod reads your BepInEx plugin configs and displays them in-game so you can edit settings without opening text files. It scans your BepInEx/plugins folder, finds which mods have config files, and creates a menu for each one.

The settings integrate into the game's existing menu system. Depending on how each mod handles its config, changes either save immediately or when you close the menu.

What It Does

  • Automatically finds all installed plugins and their configs
  • Shows plugin author, version, and GUID info
  • Detects if multiple mods are trying to use the same keybind
  • Includes a reset button to restore default settings for each config
  • Some settings apply in real-time without needing to restart
  • Allows binding gamepad buttons (see the note below)

⚠️ Note on Gamepad Rebinding

You can enable gamepad button rebinding by turning on AllowForbiddenKeyRebind in MCM's own config, but this is experimental and can cause problems. Better to wait for the dedicated Controls Rebind mod that handles this properly.

Installation

Requirements:

  • BepInEx 5.x (x86) installed (see the Guide)
  • Necropolis: Brutal Edition (Steam Version)

Steps:

  1. Download the mod using the button below
  2. Extract the ModConfigMenu.dll file
  3. Place it in BepInEx/plugins/ folder
  4. Launch Necropolis and the mod will load automatically
  5. Access mod configs through the in-game menu

How to Use

Once installed, open the game's main menu or in-game pause menu. You'll see a new "Mods" option that lists all installed plugins with config files.

Select any mod from the list to view and edit its settings. Changes save automatically depending on how each mod handles configs. Use the reset button if you want to restore config defaults.
