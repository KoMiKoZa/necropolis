BepInEx Installation Guide

So you want to mod Necropolis? Bold. Follow these five steps to install BepInEx. It's not that complicated.

Download BepInEx 5 (x86)

Necropolis is 32-bit. Head to the BepInEx GitHub releases page and download BepInEx_x86_5.4.23.2.zip (or latest 5.x x86 version). Don't grab x64 - it won't work.

Locate Your Game Directory

Find your Necropolis installation folder. On Steam: right-click Necropolis → Properties → Local Files → Browse. You should see Necropolis.exe in this folder.

Typical path: \steamapps\common\Necropolis\

Extract BepInEx

Extract the contents of the BepInEx zip file directly into your Necropolis game folder. You should now have a BepInEx folder and winhttp.dll alongside Necropolis.exe.

First Launch & Black Screen Fix

Launch Necropolis. You'll get a black screen - this is normal. Close the game. Navigate to BepInEx/config/BepInEx.cfg and find the line:
[Preloader.Entrypoint]
Type = Application

Change it to:
[Preloader.Entrypoint]
Type = MonoBehaviour

Save and launch again. BepInEx should now work properly.

Install Mods

Download Necropolis mods and place their .dll files into BepInEx/plugins/. Some mods may have additional files or folders - follow the mod author's instructions. Launch the game and your mods should load automatically.

Frequently Asked Questions

Is modding Necropolis safe?

Safer than the actual game. BepInEx is open-source and trusted by thousands. Download from reputable sources, and you'll be fine. Unlike your character in the Necropolis.

Will mods work in multiplayer?

Depends on the mod. Some work fine. Others need all players running the same setup. Check each mod's page. Or just wing it and watch chaos unfold.

My mods aren't loading. What now?

Check BepInEx/LogOutput.log for errors. Make sure files are in BepInEx/plugins/. Run the game once after installing BepInEx. Make sure your BepInEx is x86 version. Install mod dependencies. The usual troubleshooting dance.

Who owns Necropolis?

Paradox Interactive owns the IP. Harebrained Schemes made it. We're just the community refusing to let it die. No official affiliation. Just obsessed modders.
